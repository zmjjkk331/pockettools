About this image compressor

Use this free image compressor to reduce the file size of JPG, PNG and WebP images. Choose an image, adjust the output quality and maximum width, then download the compressed result. Image processing happens in your browser; your selected image is not uploaded to PocketTools.

How to use this tool

  1. Choose a JPG, PNG or WebP image from your device.
  2. Adjust output quality and maximum width if needed.
  3. Select Compress image, review the original and compressed sizes, then download the result.

Frequently asked questions

Are my images uploaded?

No. The image is processed locally in your browser and is not sent to PocketTools.

Which formats can I select?

The file picker accepts image files. The compressed download is saved as a JPEG image.

Will compression always make a file smaller?

Not always. The result depends on the original format, dimensions and selected quality.
