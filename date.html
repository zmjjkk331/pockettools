About this date calculator

Use this date calculator to find the number of calendar days between a start date and end date. You can also choose a base date and add or subtract a specified number of days to find a future or past date.

How to use this tool

  1. To count a date difference, enter a start date and an end date, then select Calculate days.
  2. To move a date, choose a base date.
  3. Select Add days or Subtract days, enter a non-negative number of days, and select Get date.

Frequently asked questions

Can I calculate a date in the past?

Yes. Choose Subtract days and enter the number of days to move backward.

Does the date difference include both the start and end date?

The displayed difference is the elapsed number of days between the two dates; it is not an inclusive count of both endpoints.

Does it work across months and years?

Yes. The browser date functions handle month and year boundaries.
