About this percentage calculator

The PocketTools percentage calculator helps calculate a percentage of a value and compare the value after a percentage increase or decrease. It is useful for quick discount estimates, price changes and everyday percentage calculations.

How to use this tool

  1. Enter the starting value.
  2. Enter the percentage you want to calculate.
  3. Select Calculate to see the percentage amount and the value after an increase or decrease.

Frequently asked questions

How do I calculate 15% of a number?

Enter the number as Value and enter 15 as Percentage, then select Calculate.

Can I use this for discounts?

Yes. The result includes the value after a percentage decrease, which can help estimate a discounted price.

Does it support decimal percentages?

Yes. You can enter decimal values and percentages.
